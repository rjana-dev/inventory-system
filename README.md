# Inventory Management System (MERN)

## Project Overview
This is a simple inventory management system built using the MERN stack.

## Tech Stack
- MongoDB
- Express.js
- React (Vite)
- Node.js

## Features
- Add products
- View products
- Backend API integration

## How to Run

### Backend
cd server  
npm install  
npm run dev  

### Frontend
cd client  
npm install  
npm run dev

Currently building core features (CRUD operations)
